# Bluewser (Wechr)

**Новый браузер для Вашего телефона (Android 9+).**
**Имеет следующие штуки:**

**• Система расширений Webview Extensions (на основе chrome extensions api, но есть и свои api, это можно узнать в bluewser://info );**
**• Превращение из браузера в приложение и обратно;**
**• Блокиратор рекламы;**
**• Прочее штуки.**
